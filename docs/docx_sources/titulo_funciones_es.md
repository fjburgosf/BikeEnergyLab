Plataforma de software científico para modelar el consumo de energía, la autonomía y la probabilidad de misión de bicicletas eléctricas. Permite configurar bicicleta, ciclista, motor, batería, ruta y ambiente, simular perfiles de velocidad prescritos y calibrar parámetros físicos con observaciones. Ofrece entrenamiento, almacenamiento, recuperación y adaptación de modelos residuales CGPRA, análisis de incertidumbre y sensibilidad, importación de rutas CSV o GPX y conversión de telemetría de sensores. Incluye nueve ejemplos sintéticos y un tutorial integrado de ocho pasos. Conserva resultados, configuración, datos y metadatos mediante exportación CSV, JSON, YAML y figuras PNG, SVG y PDF. La versión 1.0.0 ofrece interfaz de escritorio en español e inglés, API, línea de comandos y un ejecutable portátil para Windows x64. Sus pruebas de software y datos sintéticos no establecen precisión con bicicletas reales. Autores: Francisco Javier Burgos Flórez y Juan Guillermo Popayán Hernández. Contacto: fjburgosf@gmail.com.
