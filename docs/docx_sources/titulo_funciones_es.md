Plataforma de software científico para modelar el consumo de energía, la autonomía y la probabilidad de misión de bicicletas eléctricas. Permite configurar bicicleta, ciclista, motor, batería, ruta y ambiente; simular perfiles de velocidad prescritos; calibrar parámetros físicos con observaciones; entrenar, guardar, recuperar y adaptar modelos residuales CGPRA; analizar incertidumbre y sensibilidad; importar rutas CSV o GPX y convertir telemetría de sensores. Incluye nueve ejemplos sintéticos y un tutorial integrado de ocho pasos, y conserva resultados, configuración, datos y metadatos mediante exportación CSV, JSON, YAML y figuras PNG, SVG y PDF. La versión 1.0.0 ofrece interfaz de escritorio en español e inglés, API y línea de comandos, y un ejecutable portátil para Windows x64. Sus pruebas de software y datos sintéticos no establecen precisión con bicicletas reales. Autores: Francisco Javier Burgos Flórez y Juan Guillermo Popayán Hernández. Contacto: fjburgosf@gmail.com.
