# Evidencia científica histórica conservada

Las tablas CSV reproducen sin modificaciones los resultados sintéticos del
4 de octubre de 2026 que se presentan en el DOCX de metodología. `provenance.json`
registra sus rutas originales y hashes SHA256. No son resultados nuevos ni
mediciones de bicicletas reales.

`baseline` conserva el wheel y el registro de la revisión científica original.
El registro de la entrega actual distingue sus pruebas de software y GUI de
esta evidencia histórica. Estos archivos permiten regenerar los documentos
y comprobar la continuidad del núcleo desde una copia del código fuente.
